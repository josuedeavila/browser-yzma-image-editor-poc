Editor de imagens para anúncios do Mercado Livre — local, no browser

Ajusta uma foto de produto pras regras de imagem do Mercado Livre — tudo no navegador, sem enviar a imagem pra lugar nenhum. O editor (recorte/enquadramento/ resolução) é Canvas2D puro; a checagem visual é opcional e usa um modelo de visão rodando via yzma (llama.cpp como WebAssembly). Ver web/rules.js pelas regras e fontes, e a seção "Performance sem GPU" do README.
